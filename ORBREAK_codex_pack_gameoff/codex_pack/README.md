# ORBREAK（仮題）

円形フィールドの2Dブロック崩し × 倍々連鎖 × ローグライト。Godot 4.x / GDScript。

## 使い方
1. 2026年11月1日（テーマ発表後）に GitHub で公開リポジトリを作り、このフォルダの中身を置く。
2. Codex に `CODEX_START.md` の「1回目」の指示を渡す。
3. 以降はタスク1つずつ進め、M1 終了時に実機で手触りを確認して `data/balance.json` を調整する。
