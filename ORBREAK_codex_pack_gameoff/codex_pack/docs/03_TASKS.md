# 03_TASKS — 実装タスク一覧

上から順に1つずつ実装する。**【J】** が付いたタスクは GitHub Game Off 2026 のジャム版に必須（`docs/05_GAMEOFF_PLAN.md` 参照）。各タスクは「完了条件」をすべて満たしたら `[x]` にする。
M1 の終わりで人間が実機で手触りを確認し、`data/balance.json` を調整する。

## M0 プロジェクト準備

### [ ] T00 【J】プロジェクト作成
- Godot 4.x プロジェクトを作成。縦 720×1280、stretch mode `canvas_items`、aspect `expand`、物理 60Hz。
- `02_TECH_SPEC.md` のディレクトリ構成を作る（空ファイルでよい）。
- GUT を `addons/gut` に導入し、ダミーテスト1本が headless で通る。
- InputMap に `rotate_left`(Q), `rotate_right`(E), `launch`(Space/マウス左), `pause`(Esc) を登録。
- **完了条件**：エディタで実行すると濃紺の背景が表示される。`godot --headless -s addons/gut/gut_cmdln.gd -gdir=res://tests -gexit` が成功する。

### [ ] T01 【J】オートロード
- `Events`（シグナル一覧は TECH_SPEC 7章）、`Balance`（balance.json を読み、度→ラジアン変換済みの値を返すアクセサ）、`GameState`（スコア、残機、RunStats）を作成し登録。
- **完了条件**：`Balance.get_value("ball.speed")` のようなドット区切りで値が取れる。存在しないキーはエラーログを出してデフォルト値を返す。テストあり。

### [ ] T02 【J】SeededRng と Collision
- TECH_SPEC 4-1, 4-3 を実装。
- **完了条件**：TECH_SPEC 11章の該当テストがすべて通る。

## M1 手触りの核（最重要）

### [ ] T10 【J】アリーナとパドル
- `game.tscn` に Arena（中心 C）、パドル軌道の円（`draw_arc`）、パドル（円弧）を描画。
- PC：マウス角度にパドルが追従（最大角速度あり）。スマホ：ドラッグで相対移動。
- **完了条件**：PC とスマホ（エディタのタッチエミュレーション可）でパドルが軌道上を滑らかに回る。

### [ ] T11 【J】ボール
- ボールの発射（パドルにくっついた状態からタップで内向きに発射）、直進、パドルでの反射（TECH_SPEC 4-5）、喪失判定。
- この時点では惑星なし。ボールは中心を通過して反対側のパドル軌道へ飛ぶ。
- **完了条件**：パドルの中心で打つと真内向き、端で打つと最大60°傾いて飛ぶ。打つたびに速度が上がり上限で止まる。取り損ねるとボールが消え、再びパドルにくっつく。

### [ ] T12 【J】BlockGrid と惑星の表示
- `BlockGrid`（TECH_SPEC 4-2）と `planet_loader.gd`（JSON の layout 読み込み）を実装。
- `PlanetView` で MultiMesh 描画。層ごとに色を変える（表層シアン、マントル橙、コア白金）。ハードは耐久で明度を変える。
- 惑星の回転（Q/E、画面下の回転ボタン）と、ステージの自転（`spin`）。
- **完了条件**：`s1_01.json` が円形に表示され、回転操作で回る。BlockGrid のテストが通る。

### [ ] T13 【J】ボールとブロックの衝突
- TECH_SPEC 4-4 の方式で、回転する惑星に対してボールが反射し、ブロックを壊す（まだ破片・得点なし）。
- **完了条件**：惑星が回転中でもボールがブロックをすり抜けない（速度最大でも）。壊れたマスは表示から消える。鏡ブロックは壊れない。

### [ ] T14 【J】手触り確認用デバッグ
- F3：FPS、ボール速度、パドル角、破片数（今は0）を表示。
- F5：ステージ再読込。F6：`balance.json` を再読込して即反映（実行中の調整用）。
- **完了条件**：実行中に balance.json を編集して F6 で速度などが変わる。

> **M1 終了時：人間が実機で触り、ボール速度・パドル幅・反射角・回転速度を調整する。**

## M2 連鎖と縦切り試作

### [ ] T20 【J】破壊キューと得点
- TECH_SPEC 4-8, 4-9 の破壊キュー、`ChainScore`。ボール由来1点。
- HUD にスコア表示。
- **完了条件**：ブロックを壊すとスコアが増える。ChainScore のテストが通る。

### [ ] T21 【J】破片と倍々連鎖
- `ShardPool`、`ShardView`（MultiMesh）、破片の放射、ブロック衝突、段数の引き継ぎ、`ChainTracker`。
- 爆薬の誘爆。鏡での破片反射。
- HUD に現在のチェインの最大段数を「x16」のように表示（2^(段数+1)）。
- **完了条件**：1発のボールから連鎖が広がり、得点が 1, 2, 4, 8… と増える。破片3,000個でも落ちない（PC で確認）。ShardPool のテストが通る。

### [ ] T22 【J】スタンと連打復帰
- 破片がパドルに当たるとスタン。`StunController`（TECH_SPEC 4-10）。
- HUD に「連打！ 3/7」表示。3秒で失敗し残機-1。
- ハートブロックの出現（段数6以上）と効果。
- **完了条件**：スタン、連打復帰、必要数の増加、ハートでのリセット、タイムアウト失敗がすべて動く。テストが通る。

### [ ] T23 【J】再生ブロック
- TECH_SPEC 4-11。
- **完了条件**：`s1_02.json` で再生ブロックが時間とともに増え、惑星半径の外に出ない。テストが通る。

### [ ] T24 【J】ステージクリアと失敗
- 全コア破壊（コアがなければ全破壊、鏡は除く）でクリア。残機0で失敗。
- 残機・ボール数の HUD 表示。
- **完了条件**：クリア時に「CLEAR」、失敗時に「GAME OVER」を表示し、タップでタイトルへ戻る。

### [ ] T25 【J】強化と短縮ラン（ジャム版は6種）
- `UpgradeDB`（upgrades.json 読み込み、レアリティ重みで3択抽選、max_stack 考慮）。
- 強化選択画面（カード3枚）。RunStats へ効果を適用し、ゲーム側が参照。
- 短縮ラン：s1_01 → 強化 → s1_02 → 強化 → s1_03 で終了。
- ジャム版は shard_plus、shard_range、chain_boost、wide_paddle、multiball、pierce の6種。残り4種はジャム後。
- ジャム版のラン：s1_01 → 強化 → s1_02 → 強化 → s1_03 → 強化 → 最終ステージ（コアの耐久を高くした惑星、または特殊挙動1種）。
- **完了条件**：対象の強化がすべて効果を発揮する。同じシードなら同じ3択が出る。

### [ ] T26 【J】エンドレスモード
- `endless.json`。クリア判定なし、残機1。再生間隔は `regen_interval_override`。
- ハイスコアを `user://save.json` に保存。
- **完了条件**：タイトルからエンドレスを遊べ、ハイスコアが残る。

### [ ] T27 【J】気持ちよさの演出（最小）

- **完了条件**：大連鎖が視覚と音で明らかに気持ちよく分かる。

### [ ] T28 【J】タイトル・リザルト・設定
