# 01_GDD — ゲーム仕様書（2D版）

ORBREAK（仮題） 第2版 2026-10-17

## 1. コンセプト

**「惑星を回せ。砕け。連鎖させろ。」**

画面中央に円形の「惑星」（ブロックの集まり）があり、その外周の円軌道をパドルが回る。
パドルでボールを内側へ打ち返し、惑星のブロックを外側から削っていく。
ブロックが壊れると破片が飛び散り、破片が別のブロックを壊すと得点が倍々に増える連鎖が起こる。
惑星そのものを回転させ、狙いたい面をパドル側に向けられるのが本作の独自性。

- ジャンル：2D アクションパズル（円形ブロック崩し＋倍々連鎖＋ローグライト）
- 画面：縦画面 2D、真上から見た円形フィールド
- 1ラン：3〜8分。エンドレス：1〜3分
- プラットフォーム：Android → iOS → Steam（PC）

### 体験の柱（優先順位順）

1. **打ち返す手触り**：パドルの当たり位置で角度が変わり、狙って打てる。
2. **倍々連鎖の快感**：破片が破片を呼び、得点と画面が爆発的に派手になる。
3. **溜めと回転の駆け引き**：ブロックを溜めて一撃で大連鎖、惑星を回して狙いを作る。
4. **壊れビルド**：ローグライト強化の組み合わせで画面が破片で埋まる。

迷ったら上の順で優先する。

- フィールド中心：画面中央やや上（`balance.arena.center`）。
- 外側の円＝パドル軌道（半径 `orbit_radius`）。この円の外へボールが出たら喪失。
- 内側の円＝惑星。ブロックは「惑星半径」以内の格子に並ぶ。
- 惑星とパドル軌道の間の空間（リング）をボールが飛ぶ。

## 3. 構成要素

### 3-1. パドル

- 軌道（円周）上を移動する円弧。幅は角度で表す（初期 34°）。
- 内側の面で打ち返す。外側からの接触は無視。
- 当たり位置による反射：パドル中心からのずれを -1〜+1 に正規化し、内向きの法線から最大 ±60° 傾けて打ち返す。
- パドルの移動速度に上限（`paddle.max_angular_speed`）を設け、瞬間移動しない。

### 3-2. ボール

- 初期1個。ラン開始時とボール喪失後はパドルにくっついた状態で、タップ（クリック）で発射。
- 速度一定で直進し、ブロックと惑星外周、パドルで反射する。
- パドルで打つたびに速度 +2%（上限あり）。
- 軌道半径＋余白 より外に出たら喪失。全ボール喪失で残機を1つ失う。残機0でラン終了。

### 3-3. 惑星（ブロックの集まり）

- ブロックは正方形の格子に並び、格子の中心が惑星半径以内のマスだけを使う（円形に見える）。
- 惑星全体はノード1つの回転として回る。プレイヤー操作で回転でき、惑星によっては自転する。
- 惑星の層構造（外から）：**表層 → マントル → コア**。層は「中心からの距離」で決まり、色が変わる。
- 全コアブロックを壊すとステージクリア（コアが無いステージは全破壊でクリア）。

### 3-4. ブロックの種類

| ID | 名称 | 耐久 | 破片数 | 特徴 |
|---|---|---|---|---|
| normal | ノーマル | 1 | 2 | 基本 |
| hard | ハード | 2〜3 | 2 | 叩くたびに色が変わる |
| bomb | 爆薬 | 1 | 6 | 破壊時に隣接8マスにもダメージ1 |
| core | コア | 5 | 4 | クリア条件。中心付近にある |
| regen | 再生 | 1 | 2 | 一定間隔で空いている隣接マスに増殖する |
| mirror | 鏡 | 不壊 | - | ボールも破片も反射。破壊不可 |
| heart | ハート | 1 | 0 | 破壊でスタン復帰の連打数をリセット |

### 3-5. 倍々連鎖（本作の核）

- ボールがブロックを壊す：**1点**（連鎖段数 0）。
- 壊れたブロックから破片が放射状に飛ぶ。破片は自分を生んだ連鎖の段数を持つ。
- 段数 d の破片がブロックを壊すと **2^(d+1) 点**、そのブロックからは段数 d+1 の破片が出る。
  - つまり 1 → 2 → 4 → 8 → 16 …
- 1回の破壊で得られる点の上限は 9,999 点（強化で解放可）。
- ボール1回のヒットから始まった連鎖を「1チェイン」とし、チェイン中の最大段数を HUD に「x16」のように表示。
- 破片は直進し、寿命（距離）が尽きるか、パドル軌道に達すると消える。
- 破片は他の破片とは当たらない。
- 破片が鏡ブロックに当たると反射する（寿命は継続）。

### 3-6. 破片の危険とスタン

- 破片がパドルに当たるとパドルが **スタン**（操作不能）。ボールは飛び続ける。
- 画面のどこでも連打（タップ／クリック／ボタン）して復帰する。
- 必要連打数：1回目 5回、スタンするたびに +1（上限 15）。
- スタン中に 3.0 秒経過で復帰に失敗し、残機を1つ失ってボールをパドルに戻す（スコアは保持）。
- ハートブロックを壊すと必要連打数が 5 に戻る。
- ハートは「1チェインで段数6以上」に達した時、惑星の空きマスにランダムで1つ出現する（同時に最大1つ）。

### 3-7. 溜めて爆破

- 再生ブロックは `regen.interval` 秒ごとに、空いている隣接マス（上下左右）のどれか1つに増殖する。
- すぐ壊せば安全で低得点、溜めて密集させてから撃てば大連鎖で高得点、という駆け引きを作る。
- 増殖は惑星半径の外には出ない。全マスが埋まったら増殖しない。

### 3-8. 惑星の回転

- 回転操作：スマホは画面下の左右ボタンを押している間回転。PC は Q/E キー。
- 回転速度は `planet.rotate_speed`（度/秒）。
- 惑星の個性によっては自転（一定方向に常に回る）する。

## 4. 操作

| 操作 | スマホ | PC |
|---|---|---|
| パドル移動 | 画面上をドラッグ。指の水平移動量を軌道上の角度移動に変換（相対操作） | マウス位置の、フィールド中心からの角度にパドルが追従 |
| ボール発射 | タップ | 左クリック／スペース |
| 惑星回転 | 画面下の ⟲ ⟳ ボタンを押し続ける | Q / E |
| スタン復帰 | 画面のどこでもタップ連打 | スペース連打／クリック連打 |
| ポーズ | 右上のボタン | Esc |

- スマホのドラッグ感度は `input.drag_sensitivity`（ピクセルあたりの角度）で調整可能にする。
- オプション：「パドル追従を絶対位置にする」（指の角度にパドルが追従）を設定で切替可能。

## 5. ラン構成（ローグライト）

### 5-1. 1ランの流れ

1. ランを開始（残機3、ボール1、強化なし）。
2. ステージ（惑星）を攻略する。
3. クリアすると強化3択から1つ選ぶ。
4. 次のステージへ。セクターの最後はボス惑星。
5. 全セクタークリアでラン成功。残機0で失敗。
6. どちらの場合もスターダスト（メタ通貨）を獲得してタイトルへ。

### 5-2. セクター構成

- 全3セクター × 4ステージ（3通常＋1ボス）＝12ステージ。
- 通常ステージは `data/planets/` の定義からセクターに応じてランダム選出（シード固定）。

### 5-3. 惑星の個性（モディファイア）

| ID | 名前 | 効果 |
|---|---|---|
| spin | 自転 | 常に一定方向に回る |
| moon | 衛星 | 惑星の外を周回する不壊の小天体がボールを反射する |
| ice | 氷 | 破片の寿命が1.5倍 |
| magnet | 磁場 | ボールの軌道が中心にわずかに引かれる |
| dense | 高密度 | ハードブロックの割合が高い |

### 5-4. ボス惑星（M4で実装）

| ID | 名前 | 特徴 |
|---|---|---|
| boss_shell | 外殻 | 外周の鏡ブロックがゆっくり再生する |
| boss_runner | 逃げるコア | コアが格子内を移動する |
| boss_turret | 砲台 | コアが一定間隔でパドルへ弾を撃つ（当たるとスタン） |

## 6. 強化（アップグレード）

- ステージクリアごとに3択。レアリティ：コモン 70%、レア 25%、エピック 5%。
- 同じ強化は重ねがけ可能なものと不可のものがある（`data/upgrades.json` の `max_stack`）。
- 試作（M2）で10種、本制作（M4）で40種。

### 試作で実装する10種

| ID | 名称 | レア | 効果 |
|---|---|---|---|
| multiball | マルチボール | レア | ステージ開始時のボール+1 |
| split_on_paddle | 分裂打ち | エピック | パドルで打つたびに 15% でボールが2つに分裂（同時最大8） |
| pierce | 貫通弾 | レア | ボールが耐久1のブロックを貫通する（1ヒットにつき最大3個） |
| shard_plus | 破片増量 | コモン | 全ブロックの破片数 +1 |
| shard_range | 長射程破片 | コモン | 破片の寿命 +30% |
| chain_boost | 倍率ブースト | エピック | 連鎖の得点計算で段数 +1 として扱う |
| cap_break | 上限突破 | レア | 1回の破壊の得点上限 9,999 → 99,999 |
| wide_paddle | ワイドパドル | コモン | パドル幅 +8° |
| shard_immune | 防護膜 | レア | 破片によるスタンを1ステージ1回無効化 |
| slow_chain | スローチェイン | コモン | 段数5以上の連鎖中、0.4秒だけ時間が 0.5 倍 |

## 7. メタ進行（M4で実装）

- スターダスト＝ラン終了時のスコア ÷ 1,000（切り捨て）。
- 永続強化：初期残機+1、強化の選択肢+1（4択）、リロール1回、初期パドル幅+4° など。
- パドルの種類を解放（固有能力付き）。

## 9. 演出（気持ちよさ）

- ブロック破壊：小さな画面揺れ（段数に応じて強く）、パーティクル。
- 連鎖：段数が上がるたびに破壊SEの音階が半音ずつ上がる（12段で1オクターブ、以降ループ）。
- ヒットストップ：段数8以上の破壊が起きたフレームで 40ms 停止（1チェインで最大3回）。
- 連鎖倍率の表示：画面中央に大きく「x64!」とポップ。
- 色：表層＝シアン、マントル＝オレンジ、コア＝白金。背景は濃紺のグラデーション＋星。ネオン調の発光（WorldEnvironment の glow ではなく、2D の加算合成スプライトで表現）。

## 10. UI 画面

1. タイトル：ラン開始、エンドレス、設定、（M4）強化ショップ
2. ゲーム画面：HUD（スコア、倍率、残機、ボール数、スタン連打数）、回転ボタン、ポーズ
3. 強化選択：カード3枚
4. リザルト：スコア、最大連鎖段数、破壊数、獲得スターダスト
5. 設定：BGM/SE 音量、ドラッグ感度、パドル追従方式、画面揺れ ON/OFF

## 11. 権利面の制約

- 既存作品の名称・キャラクター・画像・音・ステージ配置は使わない。
- 本作の破片は「光の結晶」として描く（星形や甲羅の形にしない）。
