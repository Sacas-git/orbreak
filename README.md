# ORBREAK（仮題）

円形フィールドの2Dブロック崩し × 倍々連鎖 × ローグライト。Godot 4.x / GDScript。
GitHub Game Off 2026 参加作（Web 版で提出予定）。

## 現在の状態
- 仕様書のみ（2026-10-17）。ゲームのコードはジャム開始（2026-11-02 06:37 JST）以降に書く。

## 使い方（人間向け）
1. このリポジトリを Codex に開かせ、`CODEX_START.md` の「0回目」で仕様の読み合わせをする（コードは書かせない）。
2. ジャム開始・テーマ発表後に「1回目」の指示を渡し、T00 から1タスクずつ進める。
3. M1 終了時に実機で手触りを確認し、`data/balance.json` を調整する。
